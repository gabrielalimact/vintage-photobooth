# 🎞️ Vintage Photobooth

Uma cabine fotográfica vintage moderna para capturar memórias especiais com estilo retrô.

## ✨ Features

- 📸 **Captura em tempo real** com filtros vintage automáticos
- 🎨 **Design Rose & Pine** com blur central elegante
- 🖼️ **Tira de 3 fotos** estilo cabine clássica
- 🗑️ **Edição simples** - remova fotos antes de finalizar
- 💾 **Download instantâneo** da sua tira personalizada
- 🎭 **Animações GSAP** para experiência fluida

## 🚀 Como usar

1. Clique em "🎥 Abrir Câmera"
2. Tire 3 fotos com "📸 Tirar Foto"
3. Remova fotos indesejadas (botão ✕)
4. Clique em "✨ Montar Tira da Cabine"
5. Baixe sua tira vintage! 

## 🛠️ Tech Stack

- **Next.js 14** - React framework
- **TypeScript** - Type safety
- **GSAP** - Smooth animations  
- **Tailwind CSS** - Styling
- **HTML5 Canvas** - Image processing
